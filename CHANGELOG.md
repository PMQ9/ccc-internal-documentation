# Changelog

Notable, reader- or operator-facing changes to this repo — new behavior, infra, gates, docs, and
runbooks. Routine commits and refactors are left out. **Newest first.** This is config and
infrastructure, not versioned software, so entries are dated rather than tagged.

| 2026-06-07 | Header bar is now the black CCC bar on **every** page, including Settings (issue #40). BookStack strips all custom head content on `/settings/{category}` pages (a lockout guard), so those pages used to fall back to the DB primary color and showed a gold header. Fix: set the DB `app-color`/`app-color-dark` to CCC black `#1C1C1C` (the only lever that reaches those pages), and re-point `--color-primary` back to Oak in the custom head — both modes — so buttons/accents stay Oak everywhere the head loads (no regression). Trade-off: on the 4 admin-only settings-category pages in dark mode, toggle/accent indicators lose some contrast (state still shown by the checkmark's presence) | — |
| 2026-06-07 | Contact page now brand-matches the wiki — the standalone form + success pages render the same black masthead (gold-flat `#CFAE70` rule, the CCC logo lockup, the "CCC Wiki" name) and the gold-V favicon, and they finally offer a way back: the logo and a "Back to the wiki" link point at the new `CONTACT_WIKI_URL` (defaults to `APP_URL`). Logo/favicon are inlined (network-free, no Dockerfile/embed change); masthead is shared across both pages. Stays a separate styled look-alike per issue #38 (native BookStack embedding is infeasible); light/dark toggle parity tracked in #39 | — |

Guards: VPN + login-gated link + `@vanderbilt.edu` + CSRF + honeypot + rate-limit + fixed recipient.
